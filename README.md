# 每日国际新闻

按北京时间归档国际要闻，分为「新闻」和「AI 新闻」两类。每个日期使用独立文件夹，便于后续逐日更新。

## 目录结构

```text
daily_news/
├── README.md
└── YYYY-MM-DD/
    ├── 新闻.md
    └── AI新闻.md
```

## 更新约定

1. 以北京时间确定归档日期，新建 `YYYY-MM-DD/`，分别写入 `新闻.md` 和 `AI新闻.md`。
2. 每条包含事件摘要、事件或发布时间、可核对的原始报道或机构公告链接。
3. 标注整理截止时间。持续事件若数字或结论变化，更新该日文件并保留来源；未经证实的信息不写成定论。
